#Dynamic Resume Builder

A web application that allows users to create personalized resumes. The application is built with HTML, CSS, and TypeScript, offering an interactive and user-friendly interface for generating resumes with a dynamic skill section, allowing users to add and remove skills as needed.

Features
.Interactive Form: Users can fill out details such as name, contact information, education, work experience, and skills.
Dynamic Skill Section: The user can add or remove skills dynamically.
.Real-Time Preview: The user can see the resume preview in real-time as they fill out the form.
.Responsive Design: The application is fully responsive, making it accessible on various devices.
Tech Stack
HTML: Structuring the content and layout of the website.
CSS: Styling the user interface with modern design patterns.
TypeScript: Ensuring type safety and improving code maintainability.
